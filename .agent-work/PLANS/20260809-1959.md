# WaterClip 多乐器分镜编排单页应用实施计划

## 概要

- 从空目录初始化 Git 仓库，采用 Node.js、npm workspace、React + TypeScript + Vite 单页前端和 Fastify 本地服务。
- 前端使用 alphaTab 完成 MusicXML 排版、SoundFont MIDI 播放、游标、seek、轨道 mute/solo 和小节坐标查询；`.mscz` 由本地服务调用 MuseScore Studio 4 CLI 转换为 MusicXML。
- 应用自动保存在 IndexedDB，并支持导入、导出包含原谱、标准化 MusicXML、分镜数据和图片的 `.waterclip` 项目包。

## 核心架构与数据接口

- 系统划分为纯领域模型、乐谱/播放适配器、持久化与 API 适配器、React 界面四个边界。
- 核心模型包括 `ScorePart`、`ScoreRange`、`ShotGroup` 和 `Shot`；同一声部、同一区间允许多个分镜。
- 多声部框选按 Enter 创建分镜组，每个声部生成独立子卡；2–16 个声部提供横/纵分屏，4/9/16 额外提供宫格，并可拖拽交换格位。
- 本地服务提供 `/api/health`、`/api/scores/convert` 和 `/api/images/generate`。

## 界面与交互

- 使用“导演谱台”视觉语言：蓝灰设备面板、暖白谱纸、朱红播放线、黄铜状态点；桌面优先，窄屏堆叠。
- 顶部项目工具栏，左侧分镜属性，中央可框选乐谱，右侧声部 Mute/Solo，底部 DaVinci 风格故事板。
- 分镜按视觉小节和反复遍次存储；同一时间命中的分镜组全部高亮。
- 设置保存 Base URL、API Key 和 SoundFont；API Key 本机持久化但不进入项目包。

## 生图、保存与 XLSX

- `gpt-image-2` 固定生成 1280×720、medium、PNG；提示词为“乐器/声部 + 景别 + 拍摄描述”。
- 每个子卡最多一张参考图，支持上传或剪贴板；无参考图调用 generations，有参考图调用 edits。
- IndexedDB 自动保存；`.waterclip` 包含乐谱、JSON 与图片。
- ExcelJS 导出单张总表，严格五列：分镜序号、乐器/声部、景别、描述、示意图；分屏属性不导出。

## 验证、Git 与维护性

- 单元测试覆盖范围、反复、排序、分屏、提示词和 mute/solo；集成测试覆盖 MuseScore 与生图代理；端到端覆盖主流程。
- Git 形成可回滚提交，不推送、不创建 PR。
- 复杂度集中在乐谱时间映射和分镜组领域模型，服务端仅负责转换和 API 代理。
