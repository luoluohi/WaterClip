# WaterClip 第二轮总谱交互与性能实施计划

## 验收范围

1. `Ctrl+D` 是唯一清除框选方式；缩放会清除选区；选区蓝色更淡。
2. 按住 Ctrl 拖拽可在现有选择上追加或反选声部/小节。
3. 框选越过乐谱视口边缘时自动滚动。
4. 小节编号悬浮在谱面上方，纵向滚动时位置不变，滚动保持顺畅。
5. 恢复完整乐器名标签，并将 M/S 做成较短附加按钮。
6. 定位并修复偶发 MSCZ 转换 422 导致无法播放问题。
7. 1–16 声部等领域错误转换为悬浮信息，不抛至控制台。
8. 乐谱可拆至独立窗口并在多屏显示。
9. 工作区快捷键全局一致，按钮焦点不再改变 Enter 等快捷键语义。
10. 新分镜默认近景；设置中可接入 LLM 辅助生成参考图提示词；粘贴剪贴板改为与上传并排的按钮。
11. 播放命中的分镜对应声部/小节使用第三种高亮；提供声部小节/分镜统计面板。
12. 使用覆盖式定制滚动条；进度条与播放按钮水平居中，段落标不推移进度条。
13. 提供真实、可关闭的渲染加速选项，并验证不会破坏乐谱交互。

## 边界与验证

- 框选组合、滚动目标、快捷键和统计规则优先下沉为纯函数并覆盖单元测试。
- alphaTab 生命周期、像素边界、播放状态和窗口同步归 `apps/web/src/score`。
- 跨区工作区状态归 Zustand；LLM 与 MuseScore 转换安全边界归 Fastify。
- 使用本机 `example.mscz` 验收，不上传、不复制为夹具、不提交。
- 完成后运行 `npm test`、`npm run typecheck`、`npm run build`，检查桌面与窄屏，再归档本计划。
