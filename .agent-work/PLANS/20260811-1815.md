# WaterClip 多乐器分镜编排单页应用实施计划

## 架构与工具链

- 从空目录初始化 Git 仓库，使用 Node.js 22+、npm workspaces、React + TypeScript + Vite 和 Fastify。
- 领域模型、持久化/XLSX、alphaTab 乐谱适配器、React UI 与 Fastify 服务保持清晰边界。
- alphaTab 负责 MusicXML 排版、MIDI/SoundFont 播放、seek、播放游标、轨道 Mute/Solo 和边界查询；Fastify 调用 MuseScore Studio 4 CLI 将 MSCZ 转为 MusicXML。
- 本机 MuseScore 默认路径为 `C:\Program Files\MuseScore 4\bin\MuseScore4.exe`，同时支持环境变量和设置面板覆盖，并校验路径与版本。

## 分镜与分屏

- `ScorePart` 表示稳定乐器/声部，钢琴等多谱表仍是一个属性和一个监听单元。
- `ScoreRange` 保存视觉小节范围与播放遍次；`ShotGroup` 保存范围、分屏布局和多个 `Shot` 子卡。
- 多声部框选后按 Enter 创建一个分镜组，每个声部生成独立子卡；保留选择以便连续创建近景、特写等补拍。
- 同一声部、同一区间允许任意多个分镜；分屏支持 2–16 格横/纵等分及 2×2、3×3、4×4 宫格，格位可交换。

## 界面与交互

- 使用“导演谱台”视觉语言：蓝灰外壳、暖白谱纸、朱红播放提示、黄铜状态标记；使用 Noto Sans SC 与 IBM Plex Mono。
- 顶部提供项目、导入、播放、导出、设置；左侧编辑分镜；中央显示可缩放横向总谱；右侧为声部监听；底部为 DaVinci 风格故事板。
- 三个外围面板均可折叠，窄屏改为纵向堆叠，页面本身不产生右侧或底部空白。
- 拖拽框选吸附为“声部集合 × 连续小节范围”；语义范围进入持久化，像素坐标只存在于乐谱适配器。
- 每个小节显示编号；青色表示框选，朱红表示播放；每个乐器铭牌下方提供 M/S。
- 进度条展示所有谱面乐段 A/B/C…，支持拖动 seek 并同步移动乐谱视口。
- 可在设置中开启整页自动翻谱，只在当前视口播完时向右移动，并保留上一页末小节。
- 故事板按起始小节稳定排序；支持 `Ctrl+Z`、`Ctrl+Shift+Z` 和 `Del`，输入控件不拦截原生编辑。

## 生图、保存与导出

- 设置面板保存 Base URL、API Key、MuseScore 路径和本机播放偏好；密钥不进入项目包或服务日志。
- 图片模型固定 `gpt-image-2`、medium、1280×720 PNG；提示词为“乐器/声部 + 景别 + 拍摄描述”。
- 每张子卡可上传或粘贴一张参考图；无参考图调用 generations，有参考图调用 edits。
- 项目与图片自动保存到 IndexedDB；`.waterclip` 保存原谱、标准化 MusicXML、分镜 JSON 和图片，排除 API Key。
- ExcelJS 导出严格五列 XLSX，每个声部子卡一行；分屏属性不导出，示意图以缩略副本嵌入。

- 为范围匹配、重复遍次、自动排序、分屏布局、提示词、Mute/Solo、seek、翻页、快捷键、MuseScore 路径校验与安全代理增加回归测试。
- 使用本机 `example.mscz` 验收转换与解析，但不得上传、复制为夹具或提交 Git。
- 运行 `npm test`、`npm run typecheck`、`npm run build`，并检查 1440px、1280px 和窄屏布局；无法自动控制真实 Edge 时如实记录人工验收项。
