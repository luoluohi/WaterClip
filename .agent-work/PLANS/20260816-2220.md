# WaterClip 0.1.0 完整迁移与开源发布计划

日期：2026-08-16

## 目标

把已在 Windows 便携构建中验证的改动迁移回提交 `593816fbf118d627e15ae317823ac52f8cade6c0` 的完整源码，并生成可发布到 `https://github.com/luoluohi/WaterClip` 的 GPL-3.0-only Release。

## 实施项

1. MuseScore
   - 保留 MSCZ 转换与 PDF 排版所需的 MuseScore Studio 4 CLI。
   - 从设置和浏览器 API 参数中移除用户自定义路径。
   - Windows 便携包内聚合 MuseScore 4.7.4，并保留受控自动发现与版本校验。
2. 项目与表格体积
   - `.waterclip` 使用 ZIP Deflate level 9，只保存实际引用图片；大图限制到 1600 x 900，并在更小时转 JPEG。
   - XLSX 图片裁剪到 384 x 216，JPEG quality 0.76，同一 asset ID 只嵌入一次。
3. UI 与交互
   - 移除独立乐谱窗口及相关同步代码、按钮和样式。
   - 使用 `FolderOpen`、`FileX`、`FileMusic` 图标。
   - 设置页显示版本号；工程名支持原位重命名及撤销历史。
   - 粘贴图片注册为分镜 `imageAssetId` 并立即显示。
   - “应用到同类型分镜”以“参考图/描述”复选框控制字段范围。
4. PDF
   - 文件名使用“制片标记谱.pdf”。
   - 仅使用 MuseScore 官方页眉显示页码，首页无页码，其他页不添加项目名、临时文件名或 `Full Score`。
5. 开源与发布
   - WaterClip 采用 GPL-3.0-only。
   - 更新 README、审计、第三方许可证和 MuseScore 对应源码材料。
   - 启动入口改为 `点我开始.bat`，移除 VBS/旧说明入口。
   - 发布包包含 BAT 启动器，不包含用户项目、测试乐谱、日志或 PID。

## 验证

- `npm test`
- `npm run typecheck`
- `npm run build`
- `npm run audit:open-source`
- 使用桌面 `snezhnaya.waterclip` 验证参考图粘贴、字段范围应用、项目/XLSX 体积和 PDF 页码。
- `npm run release:portable`
- `npm run release:verify`
- 检查 Release ZIP、MuseScore 源码 ZIP 和 SHA-256。
