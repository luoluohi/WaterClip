# WaterClip PDF 导出、凭据拆分与时间线联动实施计划

## 目标

1. 以 MuseScore Studio 4 的分页结果作为 PDF 底稿，紧凑排版且不产生额外空白页；按声部与小节叠加 30% 紫色分镜标记及镜头描述小字。
2. 在本机设置中分别保存 LLM 与图像生成的 Base URL/API Key，旧版共用设置安全迁移但项目包仍不包含密钥。
3. 新增默认开启的“播放联动”设置：播放时谱面和故事板自动跟随；点击故事板时播放进度、谱面和故事板选中状态同步跳转。

## 架构边界

- `apps/server/src/score-pdf.ts` 负责临时文件、MuseScore PDF/坐标输出与 PDF 注释，不持久化乐谱。
- `apps/web/src/store` 负责设置默认值与迁移，避免凭据读取散落到 UI。
- `apps/web/src/score` 仅暴露语义小节 seek；时间线跟随逻辑通过纯函数测试后由 React 绑定 DOM 滚动。
- `App.tsx` 仅收集当前项目数据、调用导出接口与连接现有控件。

## 验证

- 服务端测试：输入校验、临时目录清理、MuseScore 失败、标记映射、PDF 响应。
- 前端测试：旧设置迁移、两套凭据独立使用、联动默认值、故事板点击 seek 与播放自动跟随规则。
- 本机 `example.mscz` 只用于验收；不上传、不复制为夹具、不提交。
- 导出实际 PDF 至 `output/pdf/`，用 Poppler 逐页渲染到 `tmp/pdfs/`，检查空白页、标记透明度、描述可读性与页边距。
- 完成后运行 `npm test`、`npm run typecheck`、`npm run build`，更新文档并归档本计划。
